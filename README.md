## 🚀 Want to run around my little burrow?

Yay! A new friend! 💕

### What you'll need

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Android Studio](https://developer.android.com/studio)
- Android SDK and a connected Android device or emulator
- Git

### Get started

**1. Clone the repository**

```bash
git clone https://github.com/neko7123/RoutineBunny.git
```

**2. Enter the project folder**

```bash
cd RoutineBunny
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Check your development environment**

```bash
flutter doctor
```

**5. Run RoutineBunny**

```bash
flutter run
```

**6. Build a release APK**

```bash
flutter build apk --release
```

If the project uses additional local configuration or assets that aren't included in the repository, configure those before running the app.
